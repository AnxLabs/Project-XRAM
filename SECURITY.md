# Security policy

XRAM is an experimental research prototype and is not suitable for internet exposure or production-sensitive data. Use only disposable credentials and isolated trusted-network tests. The shared token grants equal access to permitted clients. Memory limits are payload limits, not full process limits, and disconnects do not automatically cancel outstanding searches.

Do not include secrets or a working exploit in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use the Security tab's private report feature. If it is not available, contact a repository maintainer privately through an established channel before disclosing details. No public response-time or support guarantee is implied.
