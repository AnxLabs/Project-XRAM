# Contributing

Thank you for helping improve XRAM. Open an issue to discuss substantial changes before implementing them. Keep changes narrow, preserve compatibility where practical, and add meaningful tests for behavior and failure paths.

Run `python -m unittest -v` before submitting a change. Benchmarks must state hardware, network, fixture, commands, sample counts, failures and limitations; do not use private data or reveal tokens, credentials or sensitive paths. Avoid touching production services or changing system memory settings. Do not claim that transparent RAM expansion is currently implemented, or extrapolate small synthetic benchmarks to production workloads. Proposals exploring the long-term distributed-memory goal are welcome with clear scope and reproducible evidence.

By contributing, you agree your contribution is offered under the repository's Apache License 2.0 unless you explicitly state otherwise. Include third-party notices and license information when applicable.
